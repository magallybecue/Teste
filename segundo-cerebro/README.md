# Segundo cérebro (vault do Obsidian)

## Como abrir
1. Instale o Obsidian: https://obsidian.md
2. Abra o Obsidian > **Abrir pasta como cofre (vault)** > escolha a pasta `segundo-cerebro`.
3. Configurações > **Plugins principais**: ative **Modelos (Templates)**, **Notas diárias** e **Backlinks**.
4. Em **Modelos**, defina a pasta de templates como `Templates`.
5. Em **Notas diárias**, pasta `Diario` e modelo `Templates/Diario`.
6. Em **Arquivos e links**, defina a pasta padrão para novas notas como `00-Inbox`.

## Estrutura (método PARA)
| Pasta | Para quê |
|---|---|
| `00-Inbox` | Captura rápida. Tudo entra aqui. |
| `01-Projetos` | Coisas com objetivo e prazo. |
| `02-Areas` | Responsabilidades contínuas: Trabalho, Estudos, Saúde, Finanças, Pessoal. |
| `03-Recursos` | Temas de interesse, ideias, leituras. |
| `04-Arquivo` | O que terminou ou ficou inativo. |
| `Diario` | Notas diárias. |
| `Templates` | Modelos de projeto, reunião, leitura, ideia, diário e revisão semanal. |

## Rotina mínima
- **Todo dia (5 min):** abra a nota diária, escolha até 3 focos, anote o que surgir.
- **Toda semana (20-30 min):** use o template `Revisao-Semanal` e esvazie o Inbox.
- **Sempre:** ao criar uma nota, ligue-a a um projeto ou área com `[[links]]`.

## Regras para não abandonar
1. Só guarde o que pode ajudar em um projeto ou decisão.
2. Uma nota, uma ideia.
3. Se uma nota ficar mais de 2 semanas no Inbox, decida: use, mova ou apague.
4. Mantenha simples: não instale plugins no primeiro mês.

## Backup
Esta pasta está no Git. Como alternativa, use o Obsidian Sync ou uma pasta sincronizada (iCloud, Drive).
